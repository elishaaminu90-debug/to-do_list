# 📝 To-Do List App (Full Mega Version)

A **full-featured To-Do List application** built in Python, featuring both a **command-line interface (CLI)** and a **Streamlit web app**.  
Supports **Date + Time deadlines**, **full professional priority levels**, **task editing**, **deletion**, **completion tracking**, and **JSON persistence**.

---

## ✅ Features

- CLI and Streamlit versions
- Add, view, edit, delete tasks
- Mark tasks as completed
- Date + Time deadlines (YYYY-MM-DD HH:MM)
- Full professional priority system:
  - Critical
  - High
  - Medium
  - Low
  - Optional
- JSON storage: tasks are saved and loaded automatically
- Streamlit web app with easy-to-use UI
- Lightweight and easy to run
- Fully documented code
